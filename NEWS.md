# rappsflyer 0.3.0
* Полный переход на AppsFlyer API V2 (поддержка Bearer-авторизации и отказ от V1 токенов, которые были отключены). Обратите внимание: теперь необходимо использовать V2 API токены.
* Обновлены базовые URL-адреса (эндпоинты) для выгрузки Pull API (сырых и агрегированных данных) на `https://hq1.appsflyer.com/api/...`.
* Обновлен эндпоинт Master API на `https://hq1.appsflyer.com/api/master-agg-data/v4/app/...`.
* Лимит выгрузки строк (`maximum_rows`) по умолчанию изменён с 1 000 000 на 200 000 в соответствии с актуальными лимитами AppsFlyer API.
* Обновлены ссылки на актуальную документацию AppsFlyer API.
